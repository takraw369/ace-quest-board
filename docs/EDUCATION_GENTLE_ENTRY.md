# ACE Education — やさしい入口 / Optional Question（2026-10-16）

## 根拠となる既存正本
- Google Drive「00_BLUEPRINT｜EDUCATION FLOW BIOTOPE」：入口から重くせず、遊び・好奇心・小さなQuestから始める。学び方（Storyteller / Coach / Teacher）と、Phase別プログレッシブ質問、足場かけのサポートモード（1 Love / 2 Love / 3 Love）を保持する。
- Google Drive「00_CANONICAL｜ACE Generative Experience Layer」：USER STATE → SCENE → NOTICE → CHOICE → OUTCOME → REFLECTION → HYPOTHESIS → NEXT QUEST。問いを生成する前の観察／体験を重視する。

## 問題
問いは学習の道具だが、すべての参加者が最初から自由に問いを立てたり、答えを説明できるわけではない。認知負荷は固定能力だけでなく疲労・不安・慣れ・環境・テーマへの関心で変わる。問いが入口の必須ゲートになると、発見前に離脱や推測的回答を誘発しうる。

## 共通ルール
- **問いは最初の入場条件にしない**。観る・聞く・眺める・短いモデルを受け取るだけでも参加可能。
- 「選ぶだけ」から始めてもよい。二択/三択の感情や観察は正解／不正解で評価しない。
- 質問は、ヒント付き・例示付き・自由記入・完全スキップの選択肢と一緒に出す。
- 初回から自由記入や自己開示を強要しない。未回答・保留・見学・中断をペナルティ化しない。
- **レベル名を本人に固定付与しない**。同一人物も日・話題・状態で適した入り口が違う。サポートはいつでも追加／撤回可能。
- 体験と知識の導線を残す。問いだけでなく例示・説明・実物・短いミニレッスンも用意し、必要に応じて順序を入れ替えられる。
- 内容上、危機や高負荷への配慮が必要なら自主的な深掘りを促さず休止・安全情報へ。

## 状態対応の足場（固定ステージではない）
0. **Observe** 見る／聴く／感じる。回答不要。
1. **React** 気になったものをタップ。「なんとなく」も可。
2. **Notice / Compare** 違いに触れる。短い見本やヒントを使える。
3. **Explain** なぜそう思ったか、自分の言葉で表す（任意）。
4. **Question / Experiment** 自分の問いを立てて小さく検証する（希望者）。

これは階級でも到達義務でもなく、必要に応じた支援の強さと表現方法の選択肢。

## 今回の実装スコープ
- 既存 /learn（Quest完了前の recommended education）に限り、表示されるQUESTIONを自動開示しない。
- 起点は「まずは気づくだけでOK」。問いは本人が「もう少し考えてみる（任意）」を開いた時だけ表示。
- 任意の次アクションを分ける：「小さく試してみる（Quest）」と「今日は眺めるだけで終える」。
- 既存 /learn の Quest完了後コンテンツ選択画面、PwaBootstrap・サーバー呼び出し・推薦や行動ログ・他者データには変更なし。
- 新しい追跡、ランキング、課金、心理診断、本人プロフィールの固定フェーズ推定なし。
