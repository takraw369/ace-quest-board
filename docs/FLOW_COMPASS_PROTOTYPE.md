# FLOW COMPASS Day 1 UI Prototype

## Preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000/flow-compass/day-1` at a phone viewport. The static
export is also generated by `npm run build` under
`out/flow-compass/day-1/index.html`.

Recommended screenshot viewports:

- iPhone 13/14: 390 × 844
- Small Android: 360 × 800
- Desktop comparison: 1440 × 1000

Capture the opening screen, the `LOCATE` interaction after moving the node, and
the final observation screen. The browser's reduced-motion emulation can be
used to verify the motion-safe variant.

## UX intent

Day 1 turns reading into a short perception experiment:

1. **ARRIVE** — press and release while noticing both the node and peripheral
   field.
2. **LOCATE** — place the center directly on a neutral body map instead of
   selecting a prescribed anatomical answer.
3. **COMPRESS / RELEASE** — move through a meaningful range and compare the
   felt quality of a narrow and open circulation field.
4. **REORIENT** — rotate the axis away from screen-up to interrupt a fixed
   orientation.
5. **RECORD** — save one observed difference and an anchor for the next check.

Each step requires one small action before `NEXT` becomes available. This makes
the route a start-to-finish experience rather than a set of explanatory cards.
Tap targets are at least 44 px, content is responsive from 360 px, and all
continuous animation stops when `prefers-reduced-motion` is enabled.

## Visual model

`CompassField` is a reusable SVG component controlled by four values:

- normalized center coordinates (`x`, `y`)
- compression (`0–100`)
- orientation (`-135°–135°`)
- interaction mode

The construction uses precise circles, elliptical circulation paths, a rotating
axis, and four overlapping ellipses as a geometric flower/receptacle. Organic
blobs, cosmic backgrounds, and glow-heavy effects are deliberately avoided.

## Data status and boundaries

The following are **recorded interaction data**, not health measurements:

- the coordinate selected on screen
- slider range and final slider value
- selected visual-axis angle
- the user's written observation and chosen next anchor

The following are **metaphors used as observation interfaces**:

- “center”
- flower / receptacle
- circulation / torus-like paths
- compression and release

The prototype makes no medical, neurological, or scientific claims. Coordinates
do not identify an anatomical structure, and the angle does not measure bodily
orientation.

## Persistence and isolation

State stays in browser `localStorage` under
`ace-flow-compass-day-1-v1`. It does not read or write the existing
`ace-quest-store`, call external services, or modify Athlete Quest data.
Malformed persisted data is clamped and sanitized before use.

The typed temporary content contract lives in
`src/types/flow-compass.ts`. When
`ace-method/flow-compass/QUEST_SCHEMA.json` is ready, adapt that external schema
to `FlowCompassQuestDefinition`; the interactive state can remain local and
separate from canonical curriculum content.
